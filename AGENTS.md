# Repository guidance

- **Review:** Once the feature works, use `/code-review` to check the diff against [CODING_STANDARDS.md](CODING_STANDARDS.md) and the originating spec, then address findings.
- **Completion:** Run `bun run checks` before handing off implementation changes; completion means the command exits successfully.
- **Commits:** Read [commit guidance](docs/agents/commits.md) before creating a commit.
- **Issues, pull requests, or triage:** Read [GitHub guidance](docs/agents/issue-tracker.md).
- **Deployment or database recovery:** Follow the corresponding [operations guide](README.md#operations).
