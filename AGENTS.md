# Repository guidance

- **Commit announcements:** End internal-only commit messages with a blank line followed by `no_announcement`; otherwise the bot announces the commit in Telegram on its next restart.
- **Deployment or database recovery:** Follow the corresponding [operations guide](README.md#operations).

## Agent skills

- **Issues and pull requests:** [GitHub tracker](docs/agents/issue-tracker.md), including external PR triage and wayfinding operations.
- **Triage:** [Label mapping](docs/agents/triage-labels.md).
- **Domain vocabulary and decisions:** [Single-context domain docs](docs/agents/domain.md).
